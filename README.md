# Wedding Invitation

QR code ဖတ်လိုက်ရင် ပွင့်လာမယ့် မင်္ဂလာ ဖိတ်စာ website ပါ။ Frontend သီးသန့် (HTML/CSS/JS) ဖြစ်လို့ build လုပ်စရာ မလိုပါဘူး၊ server လည်း မလိုပါဘူး။

| Version | Path | Theme |
|---|---|---|
| 🇲🇲 မြန်မာ | `/mm/` | Golden Royal Palace (ရွှေတံခါး၊ ပိတောက်ပန်း) |
| 🇬🇧 English | `/en/` | *coming soon* |
| 🇨🇳 中文 | `/cn/` | *coming soon* |

## Data ပြင်နည်း
ဖိတ်စာထဲက စာသားတွေ အကုန်လုံးက `mm/config.js` ထဲမှာ ရှိပါတယ်။ အမည်၊ ရက်စွဲ၊ အချိန်၊ နေရာ၊ ဖုန်းနံပါတ်၊ ဓာတ်ပုံ၊ သီချင်း စတာတွေကို အဲဒီဖိုင်ထဲမှာပဲ ပြင်ပါ။

- **ဓာတ်ပုံ:** `assets/img/` ထဲကို ထည့်ပြီး `config.js` ထဲက path ကို ပြင်ပါ (ဥပမာ `groom.jpg`)။ Portrait ပုံတွေအတွက် 4:5 အချိုး အကောင်းဆုံးပါ။
- **သီချင်း:** `assets/music/mm.mp3` ထည့်ပါ။ ဖိုင်မရှိသေးရင် ဂီတသံ အတုကို အလိုအလျောက် တီးပေးပါတယ်။
- **မြေပုံ:** `venue.mapQuery` (ရှာမယ့်စာ) ဒါမှမဟုတ် `venue.mapLink` (Google Maps share link)။

## Local မှာ စမ်းနည်း
```bash
npx serve .
# သို့မဟုတ်
python -m http.server 8000
```
ပြီးရင် `http://localhost:8000/mm/` ကို ဖွင့်ပါ။ တံခါးဖွင့်တဲ့အဆင့်ကို ကျော်ချင်ရင် `?open` ထည့်ပါ (`/mm/?open`)။
Page တစ်ခုကို တန်းကြည့်ချင်ရင် `?open&page=p2` လို့ ထည့်ပါ။

## Page ဖွဲ့စည်းပုံ (မြန်မာ)
Scroll မသုံးပါဘူး။ ဒီဇိုင်းပုံ ပေးထားတဲ့ page တွေကိုပဲ လုပ်ထားပါတယ်။
- ဝင်ပေါက်တံခါး → **Page 1** (ဘုရား) ⇄ **Page 2** (စုံတွဲ) → **Page 3** ဖိတ်စာ ⇄ **Page 4** အစီအစဉ် ⇄ **Page 5** နေရာ
- Page 1 ⇄ 2: ဖိတ်စာစာအုပ် စာရွက်လှန်သလို 3D
- Page 2 → 3/4/5 (နှင့် အုပ်စုကြား ကူးတိုင်း): ကတ္တီပါ ကန့်လန့်ကာ ပိတ်ပြီး ရွှေလက်စွပ်တံဆိပ် လက်ကာ ပြန်ပွင့်
- Page 3 ⇄ 4 ⇄ 5 (tab): 3D cube လှည့်။ tab၊ ‹ › မြှား၊ အစက်လေးတွေ၊ ဘယ်/ညာ ပွတ်ဆွဲ နဲ့ ကူးလို့ရ
- Tab တွေကြား ကူးတာက history ကို အစားထိုးပါတယ်။ ဒါကြောင့် ← / ဖုန်း back နှိပ်ရင် Page 2 ကို တန်းပြန်ရောက်ပါတယ်။
- Page 5 → **Page 6** ဓာတ်ပုံ (cube) → **Page 7** ကျေးဇူးတင်လွှာ (ရွှေအလင်း ဖြာ) → **Page 8** တံခါး ပိတ် (iris) → "ပင်မ စာမျက်နှာသို့" နှိပ်ရင် တံခါး ပြန်ပွင့်ပြီး Page 1 ကို ပြန်ရောက်
- ဓာတ်ပုံ ပြောင်းရန်: `assets/img/gallery/` ထဲ ပုံထည့်ပြီး `config.js → page6.photos` ကို ပြင်ပါ (ပုံ ဘယ်နှစ်ပုံ ဖြစ်ဖြစ်ရ၊ ၅ ပုံစီ အုပ်စုခွဲပြ)
- နောက်ခံပုံများ: `assets/img/mm-*-bg.jpg` (စာသား ဖျက်ထားပြီးသား)။ မူရင်းပုံ: `*-src.png`

## Deploy (GitHub Pages — free)
1. `main` branch ကို GitHub ပေါ် push လုပ်ပါ
2. Repo → **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)`
3. Link ရလာရင် QR ထုတ်ပါ: `https://<username>.github.io/wedding-invitation/mm/`
